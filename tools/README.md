# c92-decoder - tools

### discrete_hbridge

A development board for the discrete H-bridge design used in the c92 decoder. The H-bridge is unique in being able to operate with low-side FETs always on, while PWM is applied only to the top FETs. This mode is necessary for BEMF measurement referenced to decoder ground.

### hubert_mounts

Mounting hardware for a breadboard to be fastened atop Hubert.
